THIRD-PARTY NOTICES FOR TOOLSEER DESKTOP
=======================================
⚠ SCAFFOLD STATE — this file is LISTED BUT NOT COMPLETE, and that is deliberate.
tauri.conf.json points bundle.licenseFile at this file, so whatever is here ends up in front of the
user. Nothing in apps/desktop has been built, so this file has never been reviewed against a real
dependency tree. It is a REQUIRED-BEFORE-RELEASE item, not a finished notice file.

WHAT IS MISSING (a release must not ship without it)
----------------------------------------------------
1. The full text of the Apache License 2.0, because qpdf is Apache-2.0 and PDFium's licence file also
   incorporates it. https://www.apache.org/licenses/LICENSE-2.0
2. The per-component notices for the third-party libraries compiled into the PDFium DLL. PDFium's own
   LICENSE is an aggregate file - BSD-3-Clause for PDFium-authored code followed by the Apache-2.0
   text and further component licences - which is why GitHub's detector reports NOASSERTION for
   chromium/pdfium. Fetch https://raw.githubusercontent.com/chromium/pdfium/main/LICENSE and include
   it in full rather than summarising it.
3. The Rust dependency licence list. Regenerate it on the build machine with `cargo about` or
   `cargo license` (both need cargo, which the environment this scaffold was written in does not
   have) and paste the output here. Every crate we add is a licence we are shipping.

A CI gate should fail the release if this file still contains this "SCAFFOLD STATE" heading, or if the
generated Rust dependency list is absent.

DELIBERATELY NOT INCLUDED
-------------------------
Stirling-PDF is NOT part of this distribution. Its licence from v1.0 onwards is the paid "Stirling PDF
User License", which forbids copying, merging, distributing and sublicensing the software; shipping it
inside this installer would be exactly that. The reasoning, the quoted licence text and the three
options open to the project owner are recorded in apps/desktop/engine-manifest.json ->
policy.excluded[0] and in docs/DESKTOP.md.

MuPDF (AGPL-3.0) and Poppler (GPL-2.0-or-later) are also excluded: their licences would reach our
whole application.
