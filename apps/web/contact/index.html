Bug reports, ideas, and questions — we read everything.

Before you write

If a tool misbehaved, tell us which tool, which browser and version, and roughly how large the file was. Never send us the file itself — remember, we have no way to receive it, and you should not share documents with anyone. A screenshot of the page is usually enough.

Channels

  • Support & bugs: open an issue in the project repository (link at the page footer of the repository).
  • Feature ideas: the same issue tracker, labelled “feature request”.
  • Partnerships and press: mention “partnership” in the subject.

Support the project

The tools are free and will stay free. If you find them useful, consider supporting development through the support link at the top of the page.
