Merge PDF Files

Combine any number of PDFs into a single file. Order them exactly how you want, optionally add a bookmark per source file, and download the result — all on your device.

How PDF merging works here

Merging copies pages. ToolSeer reads each PDF you add, extracts its pages, and copies them into one new document, in list order. Page content — text, fonts, images and vector drawings — is carried across as stored in the source files, not decoded and re-encoded. Nothing is converted to images and content is never re-encoded, so the pixels you put in are the pixels you get out.

The page order is simply the list order. The top file in the list contributes the first pages of the result, the next file follows, and so on. Drag a row by its handle, or use the up and down arrow buttons, to change that order. The Sorting setting offers an automatic alternative: by file name, by file size, or by date modified. With the default Original order, the result follows exactly what you see in the list.

The Add bookmarks option writes an outline into the merged file: one bookmark per source file, named after that file, jumping to its first page. Bookmarks appear in your reader's outline or table-of-contents panel and make a long merged document much easier to navigate.

What a merge cannot carry over

Interactive features do not survive a merge. Form fields, hyperlinks and annotations are page-level structures that the copy operation does not carry into the new document, so a merged file is for reading and printing rather than for filling forms. If one of your inputs is password-protected, the merge stops with a clear message instead of silently leaving it out — open the protected file in Unlock PDF first, then merge the unlocked copy.

When a browser is the wrong tool

A browser tab keeps every input file and the output in memory at the same time, so the practical limit is a few hundred megabytes or a few thousand pages on a desktop browser. The merged file is roughly the size of its parts plus a little structure overhead, and it is produced entirely on your device — no bytes are sent anywhere. For jobs measured in gigabytes, the ToolSeer desktop app does the same work on disk.

Frequently asked questions

Are my PDFs uploaded to a server?

No. The merge runs entirely in your browser. Your files are read from disk, their pages are copied into a new PDF in memory, and the result is handed back as a download. Nothing is transmitted anywhere, and the page keeps working with your network disconnected once it has loaded.

Does merging change my pages?

No. Page content — text, fonts, images and vector drawings — is copied into the new file exactly as stored in the sources. Nothing is re-encoded, so pages look identical to the originals. Interactive features such as form fields, links and annotations are not carried over.

What order do the pages end up in?

The order of the file list: the first file's pages come first, then the next file's, and so on. Drag the rows, or use the arrow buttons, to change that order. The Sorting setting can also order the files by name, size or date modified when the merge runs.

What happens if one file is password-protected?

The merge stops and tells you a file needs its password, instead of silently leaving it out. Use the Unlock PDF tool to remove the password from that file first, then merge the unlocked copy.

What are bookmarks in the merged file?

With the Add bookmarks option on, the merged PDF gets an outline with one entry per source file, named after the file, jumping to its first page. Most readers show it in a side panel, which makes long merged documents easier to navigate.
