Split PDF

Turn one PDF into many: one file per page, files for custom page ranges, or fixed-size chunks. Optionally also produce one combined copy of everything you selected.

How splitting works here

Splitting copies pages out of your PDF into new files. In One file per page mode every page becomes its own PDF. Custom ranges lets you type which pages you want, and Every N pages cuts the document into fixed-size chunks. In every mode the original file is only read — it is never modified — and each output is a brand-new document containing copies of the selected pages, without re-encoding their content.

Ranges use the form 1-3, 5, 8-12. Each comma-separated segment becomes its own output file, so 1-3, 7 produces one PDF holding pages 1 to 3 and another holding page 7. A reversed range such as 5-3 is read as 3-5, and anything that cannot be read as a page number or range — including a segment that selects no existing page — is rejected with a clear message before any work starts.

The Also produce one combined PDF switch adds a first output named toolseer-all-pages.pdf containing every selected page in order. If a range lists the same page twice, the combined file keeps its first occurrence. Individual split files are named toolseer-part-01.pdf, toolseer-part-02.pdf and so on, with zero-padded numbers so the names stay a uniform length.

When the split produces several files, the result panel shows a download button per file plus a Download all (.zip) button. The ZIP is built in your browser from the files it just created — the page never sends your document anywhere.

When a browser is the wrong tool

A browser tab must hold the source PDF, every output and the ZIP in memory at the same time. A thousand-page document split into one file per page means a thousand tiny PDFs plus a large ZIP, which can exhaust a tab. For documents of that size, the ToolSeer desktop app does the same split on disk with no memory ceiling.

Frequently asked questions

Are my files uploaded to a server?

No. Splitting runs entirely in your browser. The PDF is read from disk, the selected pages are copied into new files in memory, and nothing is transmitted anywhere.

How do I write a page range?

Use the form 1-3, 5, 8-12. Each comma-separated segment becomes its own PDF, so 1-3, 7 produces one file with pages 1 to 3 and one file with page 7. A reversed range like 5-3 is read as 3-5, and a segment that selects no existing page — for example one past the end of the document — is rejected with a clear message.

What does every N pages do?

It cuts the document into files of a fixed size. With 5 pages per file, a 12-page document becomes three files of 5, 5 and 2 pages. Set N with the Pages per file field.

Does splitting change my original file?

No. Your PDF is only read. Every output is a brand-new file containing copies of the selected pages; the original on your disk is never modified.

How do I download all the pieces at once?

When the split produces more than one file, the result panel shows a Download all (.zip) button alongside individual download buttons. The ZIP is assembled in your browser, not on a server.
