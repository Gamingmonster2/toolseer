Our works

A running record of what ToolSeer has shipped, and what is next.

ToolSeer V3 — the browser suite

Ten PDF tools, one engine, zero servers. The current site: image-to-PDF conversion with live page previews, merge, compression with three honest levels, splitting by page, ranges or chunks, password protection and removal, page-by-page visual organisation, PDF-to-image export, and text extraction with optional OCR. Every tool processes files entirely in the browser, and every page ships with structured data, bilingual chrome and a dark theme.

The design system

One stylesheet, one icon set, one component kit, shared across every page. The mascot system gives each tool its own illustration while keeping one recognisable character.

Roadmap

  • Desktop app — the same ten tools on disk, for files too large for a browser tab. Architecture documented, build in progress.
  • OCR languages — expanding beyond English and Arabic.
  • More tools — rotate, watermark, PDF to Word, and the rest of the roadmap.
