Add Page Numbers

Number every page of a PDF so a printed stack stays in order. Choose the corner and the wording, and the file is saved with a real text layer — nothing uploaded.

What this tool writes into your file

Each page gets a short piece of real text drawn into its content, positioned from the page's own measurements. Because the number is text and not part of an image, it stays sharp at any zoom, prints cleanly, and can be selected and searched like the rest of the document. Your original pages are copied into a new file, so the PDF you started with is never modified — if you dislike the result, simply delete the copy and try another corner.

The number is drawn just inside the margin you would leave when binding a document, which keeps it clear of the printed content and away from the edge a printer might crop. The built-in font is embedded by reference rather than as a font file, so numbering a six-hundred page report adds only a few kilobytes rather than megabytes.

When you want this

  • A contract or report that will be printed and handled on paper, where a dropped page is a real problem.
  • A bundle you assembled here — merge several documents first, then number the result so the parts are easy to find and cite.
  • A document numbered wrongly, for example one that restarts at 1 halfway through: start from any number you choose and the rest follow.

What it deliberately does not do

It does not renumber existing numbers, and it cannot remove a number that is already part of the page's printed content — if the original pages already show numbers, adding more gives you two. In that case crop the margin first, or use the copies with the numbers you prefer. It also cannot draw Arabic or other non-Latin characters in the numbering text: the built-in font covers Latin letters, digits and punctuation only, and you will be told when a character had to be dropped rather than silently losing it.

Numbering a document you built here

The natural order is to merge the parts, straighten anything that came out sideways, and then number the finished file. If it needs to be smaller before you send it, compress it, and if you only need a section, split it out first so the numbers match the pages people actually receive.

Frequently asked questions

Does it change my document?

It copies your pages and draws a number on each one, then saves a new file. Your original is untouched, the existing text stays selectable and searchable, and nothing is re-encoded.

Can I skip the cover page?

Yes — switch on "Skip the first page" and numbering starts on page two. The counter still counts the cover, so the number on the second page is 2, which is what a reader expects when they hold the printed document.

Can I write "Page 3 of 12"?

Yes. Type any text in the format box and use {n} where the page number belongs and {total} for the number of pages, for example "Page {n} of {total}" or just "{n}".

Why does my Arabic text disappear from the number?

Page numbers are drawn with a built-in Latin font so the file stays small and opens everywhere. Arabic or other non-Latin characters in the format box cannot be drawn by that font, so they are dropped and you are warned — the numbers themselves still appear.
