Rotate PDF

Turn every page of a sideways scan upright and save it. One choice, one click — the rotation is written into the file, and nothing is uploaded.

What "rotating a PDF" actually changes

A PDF page carries a rotation value alongside its size. That single number tells every viewer how to turn the page before drawing it. Rotating here changes that number, which is why the result is permanent: your reader, your printer, your email recipient and their phone all inherit it. Nothing is redrawn, no pixel is re-encoded, and the text stays selectable and searchable.

The rotation adds to whatever the page already had. A page stored at 90° that you turn another 90° becomes 180°, and turning it twice more returns it to where it started — so you can keep clicking until it looks right without risking a corrupt file.

When this is the tool you want

  • A whole document is sideways — the classic case: a stack of pages scanned in landscape and saved as portrait. Choose 90° once and every page is fixed.
  • A phone photo of a document was captured in the wrong orientation and exported to PDF.
  • A print came out rotated and you want the file corrected rather than changing the printer settings every time.

When it is not

If only some pages are wrong, rotating everything would break the rest. Use Organize PDF instead: it renders every page as a thumbnail with its own rotate left and rotate right buttons, so you fix exactly the pages that need it. If the problem is order rather than orientation, the same page handles that too.

Why a sideways scan happens at all

Most flatbed scanners feed a page in one fixed direction and record whatever orientation the sheet was placed in. A stack copied in landscape therefore arrives as a portrait document whose pages are visually turned on their side, and every viewer honours that because the file itself says so. Turning the pages here corrects the document, rather than the way one program happens to display it — which is why the fix survives being emailed, printed, or opened on someone else's phone. That distinction matters: changing a viewer's own rotate setting does nothing at all for the person you send the file to.

Frequently asked questions

Does the rotation get saved into the file?

Yes. The page rotation is written into the PDF itself, so it appears rotated for everyone you send it to — in every viewer, on every device. It is not a view setting that only applies on your screen.

Can I rotate only some pages?

This tool turns every page by the same amount, which is what a sideways scan needs. To rotate individual pages, use Organize PDF: it shows every page as a thumbnail with its own rotate buttons.

Is the quality affected?

No. Rotating changes one number per page in the file's page tree; the text, images and embedded fonts are copied untouched, so nothing is re-encoded and no quality is lost.

What if the page is already rotated?

The new rotation is added to the existing one. A page already stored as 90° that you rotate another 90° becomes 180°, which is what you would expect, and repeated clicks never put the file into an invalid state.
