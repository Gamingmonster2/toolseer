Unlock PDF

Type the password that opens your PDF and download an unencrypted copy. The password is used in memory, in this tab, to derive the key: it is never uploaded, never written to disk and never included in your download. This tool does not guess passwords.

What this tool does, and what it refuses to do

This page removes standard PDF encryption from a file when you already know the password that opens it. The engine derives the key from what you type, decrypts the document and writes a new copy with no encryption dictionary. The pages, text, images, links and bookmarks are preserved; the bytes are not, because writing an unencrypted file means rebuilding its structure.

It is not a password cracker. There is no guessing, no dictionary attack, no exploiting of weak RC4 keys, and no queue that tries millions of candidates while you wait. If you do not know the password, no honest tool can open the file: encrypted PDFs are designed so that the only way in is the key. A website that promises to crack a protected PDF is either running a brute-force attack, which succeeds only when the password was very weak, or it is misleading you about what it can do.

Owner passwords and permission-only locks

Some PDFs open without any prompt but refuse to print or copy. That is an owner-password restriction: the content is readable, and the permission flags say no. This page asks for the password and hands it to the engine, which either accepts it or reports that it is wrong or missing. If a file opens for you without asking for anything, its user password is empty: leave the field blank and the engine can still rewrite it without encryption, which clears the permission flags along with it. We do not attempt to defeat a restriction without the password. Certificate-based (public-key) encryption and the DRM used by ebook stores are not the standard security handler this tool implements, so they are outside what this page can handle.

Your password stays in this tab

The password you type is used in memory to derive the decrypt key. It is never transmitted: there is no upload step and no server that could receive it. It is not written to local storage or a cookie, and it does not appear in the download. The whole operation runs as JavaScript in your browser tab, which is why the page keeps working when you disconnect from the network — and why you can watch the network panel and see nothing leave.

The output deserves the same attention. An unlocked file has no password at all, so anyone who obtains it can open it, copy it and edit it. Keep it somewhere you trust, send it the way you would send any unprotected document, and if it needs protection again, add it back with Protect PDF using AES-256.

Know what you are allowed to unlock

Use this page on documents you own or have permission to modify: your own files, contracts you are a party to, documents your organisation has given you access to, files whose password you were told. Removing protection from somebody else's document can breach copyright, a licence agreement or computer-misuse law, depending on where you are. ToolSeer cannot check ownership and does not ask; the responsibility for using the tool lawfully is yours.

When unlocking does not work

If the password is rejected, check the exact characters: passwords are case-sensitive, spaces count, and some keyboards map symbols differently. If the file turns out not to be encrypted at all, there is nothing to remove, and the copy you get back is the same document. If the file is damaged, or uses a security handler this build does not implement, the engine reports that rather than returning a half-broken copy.

Frequently asked questions

Can ToolSeer open a PDF if I do not know the password?

No. The tool needs the password to derive the decryption key, and there is no guessing step of any kind. Without the password the file cannot be opened here, or by any other honest tool. A service that claims it can is running a brute-force attack that only ever succeeds on very weak passwords.

Is the password I type sent to a server?

No. It is used in memory in this browser tab to derive the key. Nothing is transmitted, nothing is written to local storage or a cookie, and the password never appears in the file you download. You can confirm it by watching the network panel while the tool runs.

Does unlocking change what is inside the document?

No. The pages, text, images, links and bookmarks are preserved and only the encryption layer is removed. The file is rewritten without it, so the internal byte layout changes and any digital signature it carried will not survive, but what you see on the page is the same.

Is it legal to remove a PDF password?

It depends on the file and on where you live. Unlocking your own documents, or files you have been authorised to modify, is normally fine. Removing protection from somebody else's work can breach copyright, a licence or computer-misuse law. Use the tool only where you have the right to.

The password is correct but the tool rejects it. Why?

Passwords are case-sensitive and spaces count, so check the exact characters and your keyboard layout. Some documents use one password to open the file and a different owner password for permissions; try the owner password as well. Certificate-based encryption and ebook DRM are outside the scope of this tool.

What should I do with the unlocked file?

Treat it as unprotected, because it is. Anyone who obtains it can open it, copy it and edit it. If the content matters, store it somewhere you trust and add protection again with AES-256 once you no longer need it open.

Other ToolSeer tools

Once the password is gone you can reshape the document with Merge PDF, Split PDF or Organize PDF, shrink it with Compress PDF, or read it as text with Extract Text. Going the other way, Protect PDF adds AES encryption back, and PDF to Images exports the pages as pictures.
