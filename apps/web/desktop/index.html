Browser or desktop: which one do I need?

The website processes files inside a browser tab, which must keep the whole document in memory at once. That is why it is instant and private for everyday documents — and why it has a practical ceiling. A few hundred pages are comfortable; a thousand-page PDF or a thousand high-resolution photos can slow the tab to a crawl or be killed by the browser.

The desktop app removes that ceiling by design. It reads the source file once, writes intermediate results to a temporary folder on disk, and streams the output file page by page. Memory use stays roughly constant whether the job is ten pages or ten thousand. The rule of thumb: if your job is larger than a few hundred megabytes, or you want to convert an entire folder unattended, use the desktop app.

How it is built

The app is a thin native shell around the same permissively-licensed engines the website uses. Rendering and text extraction run through PDFium; merging, splitting, encryption and structural compression run through qpdf. The interface is the same ToolSeer design system you are using right now — one product, two places to run it.

  • Windows 10 / 11, 64-bit — WebView2 included with modern Windows.
  • Installer size: in the tens of megabytes — a fraction of the Java-based suites it replaces, because it ships no virtual machine and no local web server.
  • Updates: versioned releases with checksums; no background updater that phones home.

Frequently asked questions

Why do I need a desktop app when the website already works?

A browser tab must hold an entire document in memory while it works. A few hundred pages are fine; a thousand-page PDF or a thousand high-resolution photos can exhaust the tab. The desktop app streams page by page to disk, so the size of the job stops mattering.

Does the desktop app upload my files?

No. It works entirely offline on your computer. There is no server, no account and no network requirement after installation.

Which tools are included?

The same ten tools as the website: image to PDF, merge, compress, split, protect, unlock, PDF to images, organise pages, extract text — plus batch operation across folders.

Which Windows versions are supported?

Windows 10 and Windows 11, 64-bit. WebView2 runtime is required and ships with Windows 10 21H2 and later.

Is the desktop app free?

The core tools are free, the same as the website. The installer is published on GitHub Releases with a pinned version and checksums.

Prefer the browser?

For everyday documents the browser tools are the fastest option — they need nothing installed and nothing uploads. Use the desktop app when the job is big.
